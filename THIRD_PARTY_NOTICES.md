# Third-party API notices

The Mod Menu integration uses a compile-only signature shim for the optional Mod Menu API. The shim is excluded from the built Wynn AI Bridge JAR; Mod Menu must be installed separately to show the settings screen. API compatibility was checked against Mod Menu 20.0.2 for Minecraft 26.2.
